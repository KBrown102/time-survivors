# Time Survivors: Chapter 0

一个纯前端、零依赖的「幸存者-like」自动攻击 Roguelike 游戏（Canvas 2D）。
工程采用 **ES Modules** 多文件拆分，无需任何构建工具，浏览器原生加载。

> 当前为项目早期可玩版本（Chapter 0）：5 英雄 / 10 武器 / 8 敌人 / 8 被动 / 4 关卡，含三存档、技能树升级、装备槽扩展、20 分钟生存 + 小 Boss + 终局 Boss。

---

## 快速开始

需要本机装有 **Node.js**（仅用作静态服务器，不参与打包）。

```bash
# 方式一：命令行
node server.js
# 方式二：双击 start.bat（Windows）
```

然后浏览器打开：

```
http://localhost:5173/
```

> ⚠️ **必须通过本地服务器打开**，不能直接双击 `index.html`（`file://` 协议下浏览器会拦截 ES Modules 的跨文件 `import`）。
> 若 5173 端口被占用，服务器会自动顺延到 5174、5175…… 看黑窗口里打印的实际地址即可。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或 方向键 |
| 主动特技（带冷却） | `空格` |
| 暂停 / 退出本局 | `Esc` |

游戏流程：**首页 → 开始游戏 → 选择存档 → 技能树 → 开始（选关卡）→ 选英雄 → 出发 → 游戏 → 结算 → 技能树**，全程不回首页，方便连续刷养成。

## 玩法

- **自动攻击**：武器自动开火，你只负责走位躲弹幕、捡掉落。
- **升级三选一**：升级时从 3 个选项中挑 1 个（新武器 / 升阶 / 被动），未激活的养成项会被过滤掉。
- **掉落**：金币（局内即时生效）、经验（升级）、治疗、时之结晶（击败 Boss 掉落，用于技能树）。
- **Boss**：每关含 1 个小 Boss（掉落结晶）与 1 个终局 Boss（撑过时长即触发，击败即胜利）。
- **技能树**：用金币 / 时之结晶解锁节点，扩展攻击槽、增益被动、解锁英雄。

## 技术说明

- **零构建**：纯原生 ES Modules，浏览器直接加载，配合本地静态服务器即可运行。
- **渲染**：单 Canvas 2D，渲染循环内按 背景 → 掉落 → 角色 → 弹幕 → 特效 顺序分区绘制。
- **性能**：对象池（`poolGet`）复用敌人/子弹，空间网格（`Grid`）做分区碰撞，稳定支撑大量同屏单位。
- **可移植渲染后端**：当前用 Canvas 2D 已足够。若日后需要上千同屏精灵，可平滑迁移到 PixiJS（2D WebGL 批处理），对象池与空间网格逻辑可原样复用。
- **测试**：`_smoke.mjs` 用浏览器环境桩件 + 动态 `import()` 加载真实模块图，覆盖存档/关卡/技能树/战斗/胜负/UI 导航等 23 项断言：

```bash
node _smoke.mjs
```
